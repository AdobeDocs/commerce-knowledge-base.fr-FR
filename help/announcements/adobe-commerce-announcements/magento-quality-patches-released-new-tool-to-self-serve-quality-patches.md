# Publication de l’outil de correctifs de qualité : nouvel outil permettant de mettre en libre-service les correctifs de qualité

Adobe a publié l’outil de correctifs de qualité pour une disponibilité générale. Il s’agit d’un outil qui permet d’appliquer, d’annuler et d’afficher des informations générales sur les correctifs de qualité disponibles pour votre version installée d’Adobe Commerce (sur site et sur l’infrastructure cloud) ou de Magento Open Source.

Cet outil permet de résoudre plus rapidement les problèmes en libre-service. Vous pouvez ainsi appliquer facilement les correctifs recommandés par le support Adobe Commerce pour résoudre les problèmes susceptibles de se produire avec Adobe Commerce.

>[!NOTE]
>
>Vous devez utiliser l’outil pour extraire les correctifs de qualité nécessaires au cas par cas uniquement et non dans le cadre d’une approche à long terme de la maintenance du code Adobe Commerce et Magento Open Source. La mise à niveau vers la dernière version d’Adobe Commerce ou de Magento Open Source reste la meilleure méthode pour résoudre les problèmes de qualité et doit être prioritaire.

## Obtention et utilisation de l’outil de correctifs de qualité

L’outil est disponible sous la forme d’un package de compositeur. Pour Adobe Commerce sur les infrastructures en nuage, le module est inclus dans le module ECE-Tools.

Une fois l’outil installé, vous pouvez vérifier les correctifs disponibles, les appliquer ou les rétablir à tout moment.

Consultez notre documentation destinée aux développeurs pour plus de détails :

* [Correctifs disponibles dans l’outil de correctifs de la qualité](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr)
* [Notes de mise à jour de l’outil de correctifs de qualité](https://experienceleague.adobe.com/fr/docs/commerce-operations/tools/quality-patches-tool/release-notes)
