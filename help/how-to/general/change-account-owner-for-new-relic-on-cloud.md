# Modification du propriétaire de compte pour New Relic sur Cloud

Pour votre projet Adobe Commerce sur l’infrastructure cloud, vous pouvez changer le propriétaire du compte New Relic sur la page de l’interface utilisateur de New Relic. Pour obtenir des instructions détaillées, voir [Modifier le propriétaire du compte](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/) dans la documentation de New Relic.

Si l’utilisateur (auquel vous souhaitez affecter le rôle de propriétaire) n’est pas encore répertorié sur votre compte, vous devez l’ajouter au compte. Consultez [Ajout et mise à jour d’utilisateurs](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks/#add-users) dans la documentation de New Relic, en particulier la section [Interface utilisateur de gestion des utilisateurs et tâches courantes](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks/#where).

Si une personne doit être ajoutée en tant qu’utilisateur, mais qu’aucun propriétaire ou administrateur existant sur le compte ne peut l’aider, tout utilisateur Adobe Commerce ayant accès au [compte de propriétaire du partenariat Adobe Commerce de New Relic](https://account.newrelic.com/accounts/1311131/users) peut afficher tous les comptes client et ajouter des utilisateurs au nom du client.
