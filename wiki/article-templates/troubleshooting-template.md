# Dépannage du modèle d’article

Le titre doit décrire brièvement le problème, un maximum de 70 caractères est préférable.<br/>
(Exemple : « Erreur de mémoire insuffisante lors de l’installation ou de la mise à niveau ».)

Consultez [Contribution > Métadonnées](../../CONTRIBUTING.md#metadata) pour plus d’informations sur les métadonnées.

Paragraphe d’introduction ou deux paragraphes : bref aperçu du problème. Les 140 premiers caractères sont importants à des fins de SEO.

## Produits et versions concernés

* Adobe Commerce on-premise x.x.x
* Adobe Commerce sur l’infrastructure cloud x.x.x

(*Si les mêmes versions sur le cloud ou sur site sont affectées, vous pouvez dire :*)

Adobe Commerce (toutes les méthodes de déploiement) x.x.x

* Extension ou technologie concernée (par exemple Redis, Fastly) : x.x.x

## Problème

Une description claire du problème, y compris des messages d’erreur complets sous forme de texte et toutes les captures d’écran importantes.
Si ce fichier se trouve dans un journal, fournissez des détails : le journal, l’emplacement.

Supprimez les ID de projet ou les informations client spécifiques des erreurs et des journaux. Assurez-vous également que les informations sensibles ne sont pas incluses dans les captures d’écran.

Si le problème se produit dans une situation très spécifique, indiquez les étapes détaillées à suivre pour reproduire, le résultat attendu et le résultat réel au format suivant :

<u>Procédure à suivre </u> :

Conditions préalables : ... (le cas échéant).

1. Première étape.
1. Deuxième étape.
1. ....

<u>Résultat attendu </u> :

C’est ce que fait Adobe Commerce.

<u>Résultat réel</u> :

C’est ce que fait Adobe Commerce.

## Cause

Raison pour laquelle le problème se produit. Ne décrivez pas le correctif, il devrait se trouver dans la section suivante. Ignorez cette option si la raison n’est pas claire ou n’est pas importante dans ce cas.

## Solution

Comment résoudre le problème. Utilisez une liste numérotée pour les étapes.
Terminez la section avec les résultats : erreur non affichée, le déploiement fonctionne, la valeur a changé et comment voir la modification, etc.

S’il existe une solution temporaire, spécifiez-la dans une section distincte sous celle-ci.
